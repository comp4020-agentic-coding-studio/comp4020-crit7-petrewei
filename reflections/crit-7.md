# Crit 7 Reflection

## 1 The Breakthrough

The breakthrough came from Lecture 7's silent failure: rename the form's input, leave the handler reading the old name, and the handler saves nothing but still redirects, while the tests stay green because they post straight to the endpoint. I asked the agent to check my tests against the lecture, and they had the same gap, since every test built its own POST body. One test now loads the page and submits the real form as a browser would ([`8bd9ca8`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/8bd9ca8)). That test also fixed the design: to work without JavaScript, each button carries its own value, so the server can check it against the activity's groups. The test outlived the ranking it was written for. When I replaced ranking with recording my allocation, the same test submitted a "This is my group" button, now an Allocate button beside each group's name ([`186f69f`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/186f69f)), and the server checks the group exists ([`9fa711d`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/9fa711d)). The lecture's warning that other clients skip the form came back at the end: a review found that a JSON body made the endpoint return 500, and it now returns 400 ([`82a8633`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/82a8633)).

## 2 Who I Want to Be as a Developer

The lecture's table of what survives a reload, a restart and a redeploy changed what I mean by "it saves". I want to say where each piece of state lives before building, then check each of those events on its own. Here the recorded allocation lives in SQLite on the Fly volume, so one test reloads the page, another boots the server twice, and my rules require recording an allocation on the live site and reloading it after each deploy. The lecture's demo ended with passing checks but no tests for its new feature. I want the decisions I care about written as tests first. For this crit that was the clash rule I defined, including the shared-date condition that one-off meetings need.
