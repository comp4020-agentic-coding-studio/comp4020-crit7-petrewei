# Process Overview

## 1 What I Built

A page for ranking my tutorial and lab preferences from my real MyTimetable data, which flags clashing first choices and keeps the ranking in SQLite on Fly. `README.md` says what good means here.

## 2 How I Got Here

The difficulty was grounding the agent in my timetable and a harness I had decided on, rather than in guesses. MyTimetable's calendar feed only lists allocated sessions, so I pasted the group lists from its preference pages too, and the agent turned both into seed data with red tests before any code existed ([`49036b9`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/49036b9)). I defined the clash rule myself, including the shared-date condition that one-off meetings need.

The harness started as my Assignment 2 rules carried over ([`0bde893`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/0bde893)). I asked the agent to check it against Lecture 7, which showed my tests posted straight to the endpoint and would miss a renamed form field, so a test now submits the page's own form ([`8bd9ca8`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/8bd9ca8)). I then cut the file by hand ([`0b6ebb4`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/0b6ebb4)), had the agent turn rules into sensors ([`8af273c`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/8af273c)), removed two of those commit hooks along with the rules the tests now held ([`176d980`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/176d980)), and brought back privacy and session-data guards as tests instead ([`ed92df8`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/ed92df8)). A review of the plan caught that the Fly image has no `src/` directory, so the seed imports the JSON. The build then passed its tests at the first run ([`9786ddc`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/9786ddc)), and the clash flags followed ([`4780be2`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/4780be2)), then a weekly grid that I checked in a browser at desktop and phone widths ([`dcffbbd`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit7-petrewei/commit/dcffbbd)).
